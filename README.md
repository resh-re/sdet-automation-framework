# SDET Automation Framework (Java | Selenium | TestNG | RestAssured | Allure | Jenkins)

Scalable automation framework validating **UI, API, and hybrid flows** with **parallel execution**, **config-driven runs**, and **CI/CD-ready reporting**.

## Tech Stack
- Java 17, Maven
- Selenium WebDriver, TestNG (parallel)
- RestAssured (API)
- Allure (reports + failure screenshots)
- Jenkins pipeline
